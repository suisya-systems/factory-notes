# laps

工場を実際に回した記録（lap）の置き場。lap ごとに、事前に書いた手順書（`lap-N-runbook.md`）と結果の報告（`lap-N-report.md`）がある。lap 5 と lap 6 は、事前登録（`prereg.json`）、判定用のスクリプト、参照アプリ（`refapps/`）もディレクトリ `lap-5/` と `lap-6/` に置いてある。`lap-6/lap.json` は lap 6 の手順を、工場の `lap` コマンドが読む定義ファイルの形で書いたもの。lap 7 は `lap` コマンドで流した最初の周で、手順書・報告・事前登録・定義ファイル・判定用のスクリプトをすべてディレクトリ `lap-7/` に置いた（報告は `lap-7/report.md`）。lap 7 の記録は、工場のリポジトリから移したものではなく、ここに直接置いた。lap 8 の記録は、工場のリポジトリの作業用フォルダ（git 管理外の `docs/lap-8/`）から写して、ここに直接置いた。報告は `lap-8/report.md`。lap 8 の結果は、試験を採点する仕組み（工場の `src/scenario.ts`）の不具合を直したあとに採点し直したもので、報告には採点し直す前と後の両方の数字を載せてある。

これらは 2026-10-18 に工場のリポジトリ（suisya-systems/factory）の `docs/` から、コミット 4558260 の時点の内容のまま移した。工場のリポジトリは英語の本文と機能だけを持つ方針にしたため。

## 読むときの注意

- 本文中の `docs/lap-N/...` や `src/...` といったパスは、工場のリポジトリのパス。移す前の内容をそのまま残している。該当するコードは https://github.com/suisya-systems/factory/tree/4558260979271cf02890e172830f73fa7e6aaf53 で読める。
- 工場のリポジトリ内のファイル（README と `requests/`）を指していたリンクは、上のコミットの GitHub の URL に書き換えた。lap の記録どうしのリンクは、移した後も同じ相対位置でたどれる。
- `lap-5/refapps/*.ts`、`lap-6/*.ts`、`lap-8/entrance.ts` は工場の `src/` を相対パスで読み込む。動かすときは、上のコミットの工場のリポジトリの `docs/` に置き直す。
